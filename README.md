# Netflix Content Analysis (SQL Project)

## Overview

This project analyzes Netflix content data using SQL to generate insights about movies, TV shows, directors, and production countries.

## Technologies Used

* SQL
* MySQL
* Power BI
* Data Visualization

## Dataset

Netflix Movies and TV Shows dataset from Kaggle.

## Key Analysis

* Movies vs TV Shows distribution
* Top producing countries
* Most active directors
* Content ratings distribution
* Release year trends

## Project Structure

Netflix-Content-Analysis
│
├── data
├── sql
├── dashboard
└── README.md

## Insights

* Majority of Netflix content consists of Movies
* United States produces the highest number of titles
* Certain directors contribute multiple shows to the platform
